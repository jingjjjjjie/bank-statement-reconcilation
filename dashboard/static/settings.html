What is one request?
One new Codex model invocation to read or compare content. A document may need several requests; one request may compare multiple documents.
What counts?
Each started request, including failed or timed-out attempts. Reading cached results and local PDF extraction count as zero.
When the limit is reached
Completed work is saved. The workflow pauses before the next new request. It can finish early if no work remains.
How to continue
Run the command again. It resumes saved work with a fresh request allowance; cached results are reused.
What this does not limit
File count, token usage, elapsed time or daily subscription usage. A smaller request limit is not a guaranteed spending cap.
